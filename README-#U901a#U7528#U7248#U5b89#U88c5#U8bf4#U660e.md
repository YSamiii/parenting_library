# 儿童成长小草园 v7.4.0 通用版

这是不含任何儿童姓名或家庭个性化信息的通用 PWA 安装包。基础内容为 001–120，支持后续在 App 内手动检查并应用内容更新包。

## GitHub Pages 部署

1. 新建或打开用于这个 App 的 GitHub 仓库。
2. 将本压缩包解压得到的全部文件上传到仓库根目录。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，文件夹选择 `/(root)`，保存。
6. 等待 GitHub Pages 给出网址后，用手机浏览器打开并添加到主屏幕。

## 通用版内容

- 100篇去个性化整理文章，保留第001—100编号。
- 9个知识主题、14组月龄观察清单。
- 两本蒙氏书籍按书名独立分类；已整理内容链接到对应文章，其余内容保留当前章节目录。
- 搜索、年龄筛选、收藏、阅读进度、清单勾选、备份导入与导出。
- 全新“小草成长”界面、桌面图标以及浅色/深色自动适配。

阅读记录保存在当前设备中。更换设备前请先在“我的”中导出备份。
